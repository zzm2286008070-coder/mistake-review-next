# 错题回顾

为“图书 → 章节 → 来源 → 大题 → 分组 → 小题”设计的轻量离线错题本。图书只添加一次，其余目录随录入建立；无需先录整本书的题量。

## 使用

- 添加一本书，填写章节。来源、大题和分组均可选。
- 输入 `3, 5, 8, 12–15`，或点选数字，一次批量保存；完整位置相同的题（含已掌握）自动跳过。
- 勾选“记录整道大题”可省略小题；下一大题按钮、每本书最近位置自动记忆。
- 最近错题和书架按书、章、来源分组；点题号可查看或修改完整位置、查看复习历史。
- 间隔复习沿用旧项目：新题 1 天后；答对后依次 3、7、14、30 天，第五次答对掌握；答错后 1 天。
- 联网打开后支持离线。浏览器菜单“安装应用 / 添加到主屏幕”，iPhone 用 Safari 分享菜单。

## 从旧版迁移

1. 旧网页“统计与设置 → 数据管理 → 导出数据”。
2. 新网页“备份与迁移 → 导入旧版 / 新版备份”，预览后点击合并导入。
3. 新建真正的图书名称，在“整理旧书名”选择原书与目标书，填写章节、大题，预览确认归并。

兼容原项目 `wr_v3` 导出的 `{books, probs}` JSON。保留题目 ID、number、level、next、status、hist、created 和其他原字段；归并额外保存 `legacyLocation`。同 ID 且内容不同的导入记录保留为两条，不覆盖历史。不猜测旧书名结构；用户确认后归并。每次导入、归并或删除题目前保存一份本机操作前备份，可下载。该快照只有最近一次，长期备份请自行导出保存。

不同网址、浏览器和设备的数据不会自动同步；换设备需导出再导入。本项目使用独立 localStorage 键 `mistake_review_next_v4`，不修改旧站的 `wr_v3`，不读取旧站的 GitHub Token。新版支持手动 Gist 云同步（使用独立文件名），Token 仅在当前会话保存。后台推送收发代码已提供，须按 [PUSH_SETUP.md](PUSH_SETUP.md) 配置 Actions Secrets 与设备订阅后才能启用，默认未启用。

离线缓存首次联网访问后建立，浏览器清理站点数据或卸载应用可能丢失本机数据，建议定期导出。代码更新后关闭所有应用页面再打开，以启用等待中的新缓存。

## 开发

零运行依赖、原生 ES Modules、静态 GitHub Pages。

```sh
npm test
npm start
```

打开 http://127.0.0.1:8765/ 。直接双击 HTML 的 `file://` 方式不能运行模块与离线缓存。

## 部署

推送 main 后，GitHub Pages 按仓库根目录部署。若需手动配置：Settings → Pages → Deploy from a branch → main / root。Pages 只发布静态源文件，不发布本机错题。

旧版数据结构参考用户原项目 https://github.com/zzm2286008070-coder/mistake-review 。本项目为独立实现。

## 界面与主题

恢复彩色导航、卡片和四色统计的样式。主题只有一个入口：“学习统计 → 设置 → 外观”。

主题色同步控制按钮、导航、图表与页面背景，自定义主题色自动生成同色系底色。页面背景也可独立选择预设、颜色选择器或六位十六进制色值；再次选择主题色会清除两种模式的手动背景，恢复跟随主题。浅色和深色模式分别记住背景。“跟随主题”可清除本模式的自定义背景，使用主题默认底色。旧版主题偏好会自动兼容，不更改错题数据。

网页 favicon、PWA 和 iPhone 主屏幕图标使用用户提供的星星 PNG。原始文件为 `star-icon.png`，应用所需尺寸由 `python scripts/icons.py` 生成。
